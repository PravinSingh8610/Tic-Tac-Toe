# 🎮 Tic-Tac-Toe Game

A classic **Tic-Tac-Toe Game** developed using **HTML, CSS, and JavaScript**. This project brings the traditional two-player game to the web with an interactive interface and simple gameplay.

## 🌟 About The Project

Tic-Tac-Toe is a browser-based game where two players take turns marking spaces in a 3×3 grid. The objective is to get three marks in a horizontal, vertical, or diagonal row before the opponent.

This project demonstrates the use of JavaScript fundamentals, DOM manipulation, event handling, and CSS styling.

## ✨ Key Features

- 🎯 Interactive 3×3 game board
- 👥 Two-player gameplay
- ⚡ Real-time player interaction
- 🏆 Win and game-draw detection
- 🎨 Clean and user-friendly interface
- 🌐 Runs directly in a web browser

## 🎮 How to Play

1. Player 1 starts the game.
2. Player 1 and Player 2 take turns selecting empty cells.
3. The first player to get three marks in a row wins.
4. If all cells are filled and no player wins, the game ends in a draw.
